Project Title: Book Manager 

Project Description:

The Book Manager application development using react native that allows users to manage a collection of books efficiently. The application demonstrate the four basic CRUD operations: Create, Read, Update, and Delete.
Users can add book information such as title, author, and genre, view the list of saved books, edit existing books details, and remove books from the collection. The application provides an interactive mobile interface where users can easily manage book records. All updates are reflected on the screen without reloading the application.

Detailed System Flow: 

1.	The user opens the application.
    
2.	The user enters the book information:
   
-	Title
  
-	 Author
  
-	Genre
  
3.	The user chooses an action:
   
-	Add Book
  
-	Edit Book
  
-	Delete Book
  
4.	The system processes the selected action:
   
-	Adds a new book
  
-	Updates existing book details
  
-	Removes a selected book
  
5.	The system updates the book list automatically.
   
6.	The updated books are displayed on the screen using a clean and user-friendly interface.
   
7.	The process repeats whenever the user manages another book record
